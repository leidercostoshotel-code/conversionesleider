Convertidor de manuales PDF → Word

Convierte los manuales de procedimientos "SPI Swissôtel Lima" (PDF escaneado) a un documento Word editable, directamente en tu navegador. No se sube ningún archivo a un servidor: todo el proceso (OCR y generación del .docx) ocurre en tu propia computadora.

Documentos generados

    Cómo funciona (y sus límites)

    1. Cada página del PDF se rasteriza a imagen en tu navegador.
    2. Se le aplica OCR en español (Tesseract.js).
    3. Si el texto reconocido coincide con la cabecera fija de estos manuales (SPI SWISSÔTEL LIMA / N° / Área / Campo / Norma / fechas), la página se reconstruye como texto real y editable.
    4. Si una página no tiene ese patrón (formularios, organigramas, portadas), se inserta tal cual como imagen, para no perder información aunque no quede editable.
    5. El OCR nunca es 100% exacto. Revisa siempre el .docx resultante antes de usarlo.

    Esta página web es la versión para navegador del script pdf_a_word.py de este mismo repositorio: reproduce la misma lógica de reconocimiento, pero corre enteramente en el cliente (pdf.js + Tesseract.js + docx.js), por lo que funciona en GitHub Pages sin necesidad de un servidor.
